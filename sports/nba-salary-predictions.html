NBA Player Salary Predictions

A machine learning project built to see how much of NBA salary can be explained by player data

Project Overview

This project uses player performance data to estimate NBA salaries. The big question was simple: if we look at production, efficiency, team context, and a few other signals, how close can a model get to the way the league prices players?

Data Sources & Features

The model pulls from a mix of basketball and context variables, including:

  • Traditional statistics such as points, rebounds, and assists
  • Advanced metrics like PER, WS/48, and BPM
  • Team performance and market-related factors
  • Player age and experience
  • Position and role
  • Salary cap context

Modeling Approach

I compared several modeling approaches, balancing predictive strength with interpretability. The goal was not just to produce a number, but to understand what kinds of signals mattered most.

  • Random Forest Regression for feature importance analysis
  • Gradient Boosting for improved prediction accuracy
  • Regularized linear models for a clearer baseline
  • Trend-aware approaches where longer-term salary patterns mattered

What The Model Showed

One of the more interesting takeaways was how much better advanced and context-aware variables performed than surface-level box score numbers alone. Market value is still messy, but the model did a decent job of showing which kinds of production tend to get paid.

Applications

This kind of model is useful as a comparison tool more than a final answer. It can help flag players who look expensive or underpaid relative to the data, and it offers a structured way to talk about value in a league where context always matters.
