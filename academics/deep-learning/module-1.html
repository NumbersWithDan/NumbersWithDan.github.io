Introduction and Mathematical Foundations

Module 1 · Notes, worked examples, and a few pictures to connect the ideas.

Models · Probability · Linear algebra · Tensors · Gradients · Chain rule

1. The basic idea: learn a useful mapping

A model takes an input \(x\) and produces a prediction \(\hat y=f_\theta(x)\). The parameters \(\theta\) are the numbers we adjust during training. Deep learning uses multiple layers to learn intermediate representations as well as the final prediction.

For a simpler model, \(\hat y=wx+b\), training changes the slope \(w\) and intercept \(b\). A neural network applies the same idea to many connected operations, usually with nonlinear activation functions between layers.

Keep in mind: fitting the training examples is only part of the job. We want useful predictions on new examples, so validation and test data matter too.

2. Probability: describe uncertainty

Use \(X\) for a random variable and \(x\) for an observed value. A distribution tells us how likely different outcomes are.

Discrete: add probabilities

For a Bernoulli variable, \(P(X=1)=p\) and \(P(X=0)=1-p\). All possible outcomes have probabilities that sum to 1.

If \(p=0.7\), the expected value is \(0(0.3)+1(0.7)=0.7\). An average need not be a possible individual outcome.

Continuous: measure area

A density \(f(x)\) describes how probability is distributed. Probability over an interval is area under the curve:

\[P(a\le X\le b)=\int_a^b f(x)\,dx.\]

A continuous variable has zero probability at any single exact value. Density itself can exceed 1; its total area must be 1.

Three ways distributions show up

  • Joint: \(p(x,y)\) describes two variables together.
  • Marginal: \(p(x)=\sum_y p(x,y)\) sums out a discrete variable; integrate for a continuous one.
  • Conditional: \(p(y\mid x)\) describes the output once the input is known.

Mean and variance

Expectation is a probability-weighted average: \(\mathbb E[g(X)]=\sum_x g(x)p(x)\), or \(\int g(x)f(x)\,dx\) in the continuous case. The mean is \(\mu=\mathbb E[X]\); variance is \(\mathbb E[(X-\mu)^2]\), the average squared distance from that mean.

Population vs. sample: a distribution describes the process; a dataset is a finite sample from it. The sample mean \(\bar x=\frac1n\sum_i x_i\) estimates the population mean. Training similarly uses a finite sample to estimate useful model parameters.

3. Linear algebra: check the shapes first

A vector stores a list of values. A matrix stores a grid. Matrix multiplication combines inputs using weighted sums; its inner dimensions must match.

One row, worked by hand

Let \(x=[2,1,3]\) and \(w=[1,-2,2]^T\). Their dot product is \(xw=2(1)+1(-2)+3(2)=6\). Add a bias of 1 and the model's output is 7.

  • Transpose: swaps rows and columns, so a \(4\times3\) matrix becomes \(3\times4\).
  • Elementwise multiplication: multiplies matching entries. It is a different operation from matrix multiplication.
  • L1 norm: \(\|x\|_1=\sum_i|x_i|\). For \([3,4]\), it is 7.
  • L2 norm: \(\|x\|_2=\sqrt{\sum_i x_i^2}\). For \([3,4]\), it is 5.

Centering a feature

For values \([2,4,6]\), the mean is 4. Subtract it to get \([-2,0,2]\). With multiple features, compute and subtract a separate mean for each column. Estimate those means using training data, then apply them to validation and test data.

4. Tensors: arrays with more axes

In these notes, a tensor is a multidimensional array. Its shape gives the length of each axis. The number of axes is sometimes called tensor rank; this is different from matrix rank in linear algebra.

A scalar has no axes, a vector has one, and a matrix has two. A video batch might add a time axis: [batch, frames, channels, height, width]. Reshaping changes how entries are grouped; transposing or permuting changes axis order.

Common snag: broadcasting can make operations run even when your intended shapes are wrong. Write down the meaning of each axis before debugging the arithmetic.

5. Gradients: which way changes the loss?

A loss \(L(\theta)\) measures prediction error. The gradient collects its partial derivatives, one per parameter. It points toward the steepest local increase, so gradient descent steps in the opposite direction:

\[\theta_{\text{new}}=\theta-\eta\nabla L(\theta).\]

The learning rate \(\eta\) controls step size. For the toy loss \(L(w)=(w-2)^2\), the derivative is \(2(w-2)\). Starting at \(w=0\) with \(\eta=0.1\) gives \(w_{\text{new}}=0-0.1(-4)=0.4\).

6. Chain rule: connect the local changes

Backpropagation applies the chain rule through the operations of a model. A forward pass computes values; a backward pass works out how each value affects the final loss.

For a vector input and scalar loss, use a column gradient here: \(\nabla_xL\in\mathbb R^n\). For a vector-valued function \(f:\mathbb R^n\to\mathbb R^m\), the Jacobian has entries \(J_{ij}=\partial f_i/\partial x_j\) and shape \(m\times n\).

With \(y=f(x)\), the backward relationship is \(\nabla_xL=J_f(x)^T\nabla_yL\). Frameworks can compute this product without building the entire Jacobian. If an input feeds multiple paths to the loss, add the contributions from those paths.

Quick check: can you work these out?
  • A batch has shape [8, 5] and weights have shape [5, 3]. The output is [8, 3].
  • For L(w) = (w − 2)² at w = 4, the derivative is 4, so a small descent step moves left.
  • For z = 2w and L = z², dL/dw = 8w. At w = 3, that is 24.
