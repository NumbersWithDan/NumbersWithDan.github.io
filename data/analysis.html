Data Analysis Projects

Projects that start with a question and become clearer as the data gets cleaner

Urban Heat Island Analysis

One of my more complete analysis projects looks at temperature patterns across Dallas neighborhoods and asks how they line up with features like tree cover, density, and local conditions.

I like this project because it combines mapping, exploratory analysis, and a question that matters outside the spreadsheet.

Economic Trend Analysis

I have also spent time analyzing economic indicators and other business-facing data where the goal is less about building a flashy model and more about understanding what is changing, what is stable, and what deserves attention.

Customer Behavior Studies

Another recurring theme in my work is customer and user behavior. Segmentation, retention questions, and purchase patterns are all more useful when the analysis is straightforward enough to support a decision.

Methodology & Tools

Most of this work relies on Python, R, SQL, and standard visualization libraries. The real goal is not the tool stack, though. It is getting from raw data to something clean, readable, and worth acting on.

About My Data Analysis Work

I try to make analysis useful enough for decision-making without making it harder to read than it needs to be.
